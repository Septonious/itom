# ITOM

**ITOM 1.1.5 is stable and complete.** All main transport goals have been met and surpassed, with field acceptance confirmed on 8 November 2026.

[Stable release and downloads](https://github.com/Septonious/itom/releases/tag/v1.1.5) · [Release notes](releases/1.1.5/RELEASE_NOTES.md) · [Completion record](releases/1.1.5/RELEASE_STATUS.json) · [Exact released source](https://github.com/Septonious/itom/tree/v1.1.5/archives/1.1.5/source)

The user reports **290/340 Mbps peak download/upload at approximately 200 ms loaded RTT**, with no observed line disconnections and continued usability for Speedtest, Telegram and YouTube over time.

Stable 1.1.5 uses the exact field-tested APK and binaries from 1.1.5 testing. The five qualification jobs passed, including normal/race safety, video recovery under a provider fault, repeated native transfers, and Android build/tests/lint. Mailbox cleanup remains server-only with bounded storage; the qualified controller and four-folder layout are retained.

Users already running those 1.1.5 testing packages have the completed transport. No reinstall is needed for this promotion.

Historical archives and tags remain available, including [1.0.0](https://github.com/Septonious/itom/releases/tag/v1.0.0), [the transport rework plan](docs/1.1.0/TRANSPORT_REWORK_PLAN.md), and [protocol research](docs/1.1.0/RELATED_PROTOCOL_RESEARCH.md).
