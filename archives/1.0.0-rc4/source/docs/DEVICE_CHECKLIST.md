# Локальная проверка ui-final-1

Это ожидаемые результаты проверки, **не выполненные здесь Android-тесты**. Тестировать APK, собранный из 0.4.0-dev4 / ui-final-1. Здесь запущены только Python/offline checks; прежний пользовательский отзыв подтверждает принятие оформления, но не новую миграцию.

## Сборка

- Launcher печатает ui-final-1 и распаковывает исходники в новую папку. 32 Python-теста проходят.
- Локально проходят 52 Kotlin/JUnit-теста, lintDebug, compileReleaseKotlin и assembleDebug. APK появляется в dist только после gates. Полные ошибки и warnings доступны в dist/build.log и lint-results.*.
- При неудачной повторной сборке из того же дерева после offline checks/lock предыдущий выходной APK/sha этой ревизии удалён; посторонние версии сохранены. Не обходить gates для получения APK.

## Установка и очистка демо

- Обновить прежний APK с той же локальной подписью без удаления приложения. В launcher, Android app list и QS tile имя ITOM. Цветная иконка/монохромная тематическая версия сохранены.
- Чистая установка: пустой список профилей, никаких вымышленных подключений, графиков, кнопок добавления демо или имитации ошибки. QS tile только открывает приложение.
- Обновление с нетронутым встроенным демо без секретов: оно удалено; прочие профили, правила, app selection сохранены. Если демо было выбрано, выбран первый оставшийся профиль либо ничего.
- Обновление с переименованным демо/изменёнными аккаунтами: профиль сохраняется. При нехватке секретов есть «Требует настройки»; круг открывает редактор, данные не теряются. Полное заполнение credentials всех аккаунтов/Pair ID/PSK и Save снимают пометку.
- Обновление с одним введённым логином/паролем либо одним ключом: эти значения сохраняются; неполные остальные поля остаются для заполнения. С полностью заполненным бывшим демо сохраняются все секреты, профиль становится обычным.
- У обычных профилей с похожими названиями ничего не удаляется. После нескольких перезапусков миграция не повторяется и revision не растёт без изменений.
- Старое уведомление/канал itom_demo удалены. MockSessionService и foreground permissions отсутствуют. Нет notification permission prompt на круге; настройки уведомлений открывают системный экран.
- Полный профиль + круг: сразу Error с CORE_NOT_INTEGRATED, скорости/TCP/active lines нулевые, RTT неизвестен, графики пусты, значка системного VPN нет. Не ожидать Connected до реального core.

## Сохранение и редактор

- Все параметры профиля, IMAP-account CRUD/enabled и секреты редактируются. Один provider на профиль; IMAPS/проверка сертификата обязательны; локальный profile ID не меняется.
- Проверить отрицательные UID, PSK, пустые credentials, port/hostname, одинаковые account IDs и чужой Server ID: ошибка не сохраняет часть документа. Отмена оставляет прежние данные.
- Удаление аккаунта удаляет только его credentials. Новый аккаунт не копирует чужой пароль. Удаление профиля удаляет только его секреты и incomplete marker.
- Проверить отсутствие перезаписи при выборе уже выбранного профиля/сохранении тех же правил. Устаревшая revision редактора даёт конфликт; загрузка актуальных данных требует подтверждения потери черновика.
- Поворот сохраняет несохранённые поля в памяти, не дублирует Save; смерть процесса открывает записанные данные. Back/Cancel с изменениями предлагает отменить выход. При записи Back/Save заблокированы.
- На тестовом устройстве/инструментированном окружении проверить отказ записи/rename/readback: успешное сохранение не показывается; следующий edit блокируется, «Повторить» перечитывает реально записанный vault. После неопределённой записи черновик может потребовать перезагрузки по revision. Не повреждать единственное рабочее хранилище ради теста.
- Ошибка Keystore/дешифрования не создаёт пустой файл. Миграция при недоступном диске не объявляется завершённой.
- Пароли/PSK скрыты; FLAG_SECURE действует на editor/import и снимается при выходе. Экспорт метаданных и диагностики не содержит secret material; diagnostics также исключает имена/ID/hostnames/packages.

## Сохранённый UI и правила

- Главная не скроллится; круг, профиль, RTT, download/upload, TCP и active/total помещаются. Нет прямоугольной кнопки подключения и полосы сегментов линий.
- Градиенты, bloom, светлый текст и иконки видны при 320×568, 360×640, обычном телефоне, landscape, text scale 130%, увеличенном display size и трёхкнопочной навигации. TalkBack озвучивает действия.
- В реальном приложении сейчас доступны Off/Error; Connecting/Connected и остановку орбиты на произвольном угле можно проверить в существующих native IDE previews/тестах модели. Полная runtime проверка ожидает настоящий транспорт; не возвращать симулятор ради неё.
- VPN → Block → Direct, правильные цветные иконки, domain/subdomains, .ru, IP/CIDR. Проверка адреса использует сохранённые правила и не создаёт соединения.
- «Правила → Приложения» — единственный вход, полный экран. Поиск по имени/package, цветные иконки, system/selected filters, групповой shared UID, отсутствие пустого include. После удаления выбранного пакета каталог/валидация предлагают исправление. Cancel не сохраняет, Save проверяет свежий каталог.
- Исключённые приложения по контракту идут Direct мимо всех групп, включая Block; включённые используют адресные группы. В этой сборке обе политики пока являются конфигурацией, не системной фильтрацией.
