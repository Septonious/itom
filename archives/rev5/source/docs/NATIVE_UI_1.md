# ITOM 0.4.0-dev2 · Native UI 1

Дата: 2026-09-24. Source revision: `native-ui-1`. Основа — проверенный source ZIP build-fix-5; все исправления сборщика и lifecycle включены.

## Задача пользователя

Пользователь сообщил, что функционал прежней версии в целом исправен, но нативный UI не соответствует интерактивному концепту. Изучены все 7 скриншотов из uiconcepts.zip и исходный ITOM_PROTOTYPE_0.3.1.html. Референсы использованы для плотности, тёмных синих поверхностей, контуров и полноэкранного списка приложений. Порядок правил, устройство серверных профилей и поведение ITOM сохранены. Новый HTML не создавался; изображения референсов в source ZIP не включены.

## Изменения

| Область | Реализация |
|---|---|
| Общий стиль | Синий/чёрный градиент фона, диагональные градиенты карточек, тонкий светлый контур, радиусы 16–26 dp, единая типографика |
| Светящиеся элементы | Мягкие радиальные градиенты вокруг кольца, орбитального шарика и активных индикаторов; небольшой световой след графиков. Без bitmap-фонов и full-screen blur |
| Навигация | Четыре вкладки с векторными иконками и синим выделением активной; верхняя панель со статистикой и уведомлением; учёт системных отступов |
| Главная | Нет verticalScroll/LazyColumn. BoxWithConstraints распределяет доступное место: фиксируются профиль и обязательные метрики, оставшуюся высоту получает круг. При малой высоте круг и подпись располагаются рядом; широкое горизонтальное окно использует две колонки |
| Круг | Единственная кнопка подключения/отключения/отмены, четыре цвета, сохранение угла шарика. Его угол читается на стадии рисования, чтобы не перестраивать весь UI на каждом кадре. Анимация учитывает lifecycle и системное отключение анимаций |
| Метрики | Download/Upload с отдельными единицами, цветной RTT, TCP и активные/все линии. В просторной компоновке — мини-графики из реальной истории snapshot; компактная сохраняет все числовые показатели |
| Ошибка связи | Красное состояние остаётся на главной; нажатие на его подпись открывает полное пояснение, не вытесняя метрики длинным текстом |
| Приложения | Самостоятельный полный экран без основной нижней панели и общего заголовка. Поиск и Save/Cancel закреплены; параметры и строки приложений используют оставшееся пространство. Настоящие иконки загружаются по мере появления строк вне UI-потока; кэш ограничен 4 MiB |
| Выбор приложений | Все / выбранные напрямую / только выбранные в VPN, поиск по названию и package name, показ системных, фильтр выбранных, счётчик, обновление и удаление отсутствующих из черновика. Общий UID выбирается атомарной группой. Применение вновь проверяет текущий каталог |
| Правила | Цветные плитки строго VPN → Block → Direct: синяя сеть, красный крест, зелёная стрелка вверх; редактор, сохранение и тест адреса. Приложения доступны только отсюда |
| Профили | Серверные карточки с выбранным состоянием, User ID, числом линий, подробностями и прежними действиями. Экспорт не содержит ключей и паролей |
| Настройки | Оставлены уведомление и диагностика. Полностью удалены экран/пункт «О проекте», блок «Безопасность» и переключатель «Крупный текст» |

## Совместимость

- Package по-прежнему `org.itom.client.dev` для debug; versionCode повышен 4001 → 4002. Существующие профили и настройки сохраняются при обычном обновлении APK с той же подписью.
- Серийное поле `VaultDocument.largeText` сохранено только для чтения старого хранилища. Оно не публикуется в PublicConfig, не меняется через UI и больше не умножает размер шрифта. Настройка системного масштаба Android продолжает действовать.
- Domain routing, проверка приглашений, формат шифрованного vault, session generation/Stop, notification backend и оба source-set backend не переписаны. Добавлено только получение иконок к каталогу PackageManager.
- QUERY_ALL_PACKAGES и точечное исключение Lint из fix5 сохранены. Lint и тесты остаются обязательными. AGP/Gradle/Kotlin/Compose/SDK не обновлялись; для debug явно подключён ui-tooling-preview из прежнего BOM.
- Эта поставка всё ещё использует debug mock. Release сообщает CORE_NOT_INTEGRATED. Переработка UI не реализует TUN/IMAP и не подтверждает сетевую производительность.

## Фактические проверки

Выполнены offline source checks и 30 Python-тестов сборщика с `PYTHONUTF8=0` и `EncodingWarning` как ошибкой. Проверены вызовы изменённых composables, удаление трёх пунктов, отсутствие scroll-контейнера на главной, единственный вход в приложения и границы debug/release. Это статический просмотр исходников, не Android Lint или компиляция Kotlin.

Подготовлены 5 native Preview в `android/app/src/debug/java/org/itom/client/NativeUiPreviews.kt`: 393×852 connected, 360×640 и 320×568 off, 800×360 connecting, 360×740 error со шрифтом 130%. Preview используют те же Compose-функции; здесь их рендеринг не запускался. Эти сценарии нужно проверить визуально на устройстве или в Android Studio. Для минимальных окон, нестандартных OEM-шрифтов и экстремального увеличения текста результат нельзя подтвердить статическим просмотром.

Локальная команда выполняет 32 Kotlin/JUnit-теста, Lint, debug/release Kotlin compilation и assembleDebug. Готовые APK/бинарники в комплект не вложены.

```powershell
python .\ITOM_PHASE2_SOURCE_0.4.0-dev2_ui1.zip android --expect-revision native-ui-1 --accept-android-licenses
```

Проверить на телефоне после сборки: все четыре состояния круга, быстрый Start/Cancel, сохранение шарика при смене вкладки/повороте, длинное имя профиля, kbps/Mbps, высокий/неизвестный RTT; app picker с клавиатурой, тремя режимами, shared UID, скрытыми системными и удалёнными пакетами; Save/Cancel/Back; обновление поверх fix5 без очистки данных. Общий checklist — DEVICE_CHECKLIST.md.

Первичные API-источники: [Compose Brush](https://developer.android.com/develop/ui/compose/graphics/draw/brush), [Compose layouts](https://developer.android.com/develop/ui/compose/layouts/basics), [BasicText / autoSize](https://developer.android.com/reference/kotlin/androidx/compose/foundation/text/BasicText.composable). Автоматический подбор применяется локально к однострочным значениям и состоянию; глобальный системный fontScale не заменяется.
