# FIELD45 — результаты проверочного выпуска

Ревизия `transport-s1-perf5-field24`, Android versionCode `9004`, versionName `0.9.0-dev2-field24`. Дата: 7 октября 2026. Это кандидат для локальной проверки обеих сторон. Полная эксплуатационная приёмка не подтверждена.

## Изменения

- Удалён второй download-регулятор, который мог снижать темп при редких подтверждениях BODY. RTT-контроллер и ограничитель загрузки используют один admission clock.
- Стартовое окно ожидающих BODY имеет запас 1 МиБ; на быстром канале растёт до 4 МиБ. Выполняющиеся APPEND учитываются в окне. Физические квоты 8/12 МиБ и освобождение только после очистки сохранены.
- Повтор по NACK после доказанного APPEND получает DeliveryGrace 1750 мс, меньше интервала probe 2 с. Неопределённая публикация восстанавливается сразу.
- Служебные сообщения обходят занятые физические слоты APPEND/control. Общий RTT учитывает верхнюю четверть пула; единичный выброс не включает ограничение всего пула.
- Сборщик устанавливает API 29 для gomobile отдельно от SDK 37.0 приложения. Обрабатывает вложенные каталоги платформы, build-tools и NDK, сохраняет метаданные sdkmanager, отклоняет неоднозначные каталоги.
- UI FIELD43 и ранее проверенная база подключения FIELD42 FIX1 сохранены.

## Сеть 20 Мбит/с

Приёмка **НЕ пройдена**. Требования пользователя: полезная скорость минимум 5 Мбит/с и прикладной RTT максимум 1500 мс, без 10% допуска. Скорость проверяется в каждом активном направлении по всей фазе и последней трети; RTT — по максимуму проб.

Модель: общий канал 20 Мбит/с, propagation RTT 250 мс, 10 accounts, 4 потока в каждом активном направлении, фазы по 30 с, BINARY FETCH, APPEND с MIME/base64, начальные журналы 8 МиБ и 3 потерянные публикации. Локальный надёжный relay не моделирует радио, TCP-потери и поведение настоящего провайдера. Во время этого прогона Gradle также подготавливал зависимости; это дополнительное ограничение измерения.

## Запуск на Windows

Обновить и сервер, и APK. Команда:

```powershell
python .\ITOM_TRANSPORT_FIELD45_SOURCE.zip all --expect-revision transport-s1-perf5-field24 --accept-android-licenses
```

Архив содержит исходники и журналы проверок, готовые APK/AAR/серверы в него не включены. Launcher собирает их локально. Реальный Android, Windows и Rambler в этом выпуске здесь не проверены. Не объявлять FIELD45 стабильным мобильным выпуском до локальных измерений.

Машинный отчёт: `FIELD45_RESULTS.json`. Свежие журналы: `field45-checks/`. Старые FIELD44 и более ранние отчёты оставлены как история.
