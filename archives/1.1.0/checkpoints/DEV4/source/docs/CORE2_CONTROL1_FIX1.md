# core-2-control-1-fix-1

Причина сбоя: отдельный `go vet ./...` обнаружил 11 unkeyed literals
структур из пакета wire в core/flow/status_test.go: семь ByteRange и четыре
Credit. Они компилируются, но vet требует именованные поля внешних структур.

Исправление: {Start:..., End:...} и {MaxStream:..., MaxData:...}.
Числовые значения, порядок случаев и ожидания тестов не изменены. Другие
cross-package literals просмотрены: wire.ID — массив, для него positional
значения допустимы. Новые тесты, повторяющие эту синтаксическую правку, не добавлены.

Пользовательский core-build.log относится к core-2-control-1, archive SHA-256
4366d0594d14a7440f232f54f520802caeb3bf25fb0ef4837c54d908e776c16d.
Go 1.27.1 на Windows дошёл до отдельного vet после успешного go test и проверки
его JSON-результата сборщиком. Это подтверждает Go-тесты базовой ревизии,
но не успешный полный gate. Подробное число событий из этого лога неизвестно.

В Go-дереве изменён только status_test.go. Production Go, Android, зависимости
и сборочные инструменты побайтово сохранены. Vet остаётся обязательным,
его анализаторы не отключены, severity не понижена.

Исправленная поставка проверяется чистой распаковкой и offline gate. Go/vet
здесь не запускались; финальный полный gate выполняет пользователь командой
из README. Эта ревизия не добавляет новый транспортный функционал.
