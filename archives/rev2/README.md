# ITOM 0.9.2-Rev2 archive

Download assembled APK, Linux binaries, executable source ZIP and full archive from [the Rev2 prerelease](https://github.com/Septonious/itom/releases/tag/v0.9.2-Rev2). The manifest and fixed-size ZIP parts preserve the complete local bundle despite upload request limits. GitHub Actions verifies every part, assembled archive and release asset before publication.

Modified/new source files are under `source/`. The complete executable source archive is also stored in this directory. Findings and verification are under `builds/0.9.2-Rev2/` in the repository and inside the release bundle. The complete performance target is not qualified; see the preserved failed repeat results.
