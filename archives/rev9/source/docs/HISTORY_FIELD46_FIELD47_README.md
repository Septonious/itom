# FIELD47 — transport rewrite baseline

Текущая ревизия: `transport-s1-perf6-field26`. Это экспериментальный исходный кандидат переработки. Изменения, рабочие решения и границы проверки: `docs/RELEASE_FIELD47.md` и `docs/TRANSPORT_REDESIGN_DECISIONS.md`. Исторические speed targets в старых разделах ниже не заменяют текущий контракт для сети 20 Мбит/с: полезная скорость >=5 Мбит/с каждого активного направления и прикладной RTT <=1500 мс.

Сборочный localhost smoke больше не требует 27 Мбит/с: он проверяет функциональность и целостность, а точный критерий 20 Мбит/с проверяется отдельной нагрузочной моделью. Проверки и ограничения текущего кандидата: `reports/field47/validation.json`. Готовые APK и серверы находятся в отдельном `ITOM_TRANSPORT_FIELD47_BINARIES.zip`.

```powershell
python .\ITOM_TRANSPORT_FIELD47_SOURCE.zip all --expect-revision transport-s1-perf6-field26 --accept-android-licenses
```

# История FIELD46 — результаты и команды предыдущей ревизии

Ревизия `transport-s1-perf5-field25`, Android versionCode 9005. Исправления FIELD45 FIX1 сохранены. Полный стандартный прогон на Linux пройден. В модели 20 Мбит/с скорость во всех фазах выше 5 Мбит/с, но максимум RTT 3078 мс превышает предел 1500 мс: мобильная приёмка не пройдена. Результат Windows FIELD46 пока не измерен.

Очистка физической почты теперь сохраняет наблюдения и доказанные возвраты квоты пакетами до 32 попыток, с полной синхронизацией журнала на диск. Неверный участник откатывает всю транзакцию; ошибки commit блокируют журнал до восстановления. Физические UID и UIDVALIDITY проверяются по прежним правилам. Доказательства ещё не удалённой почты не возвращают квоту.

Порог сборочного теста остаётся 27 Мбит/с и 1000 мс RTT. Для сети 20 Мбит/с требуется минимум 5 Мбит/с полезной скорости и максимум 1500 мс RTT без допуска. Результаты и ограничения: `docs/FIELD46_RESULTS.md`.

Обновить сервер и APK:

```powershell
python .\ITOM_TRANSPORT_FIELD46_SOURCE.zip all --expect-revision transport-s1-perf5-field25 --accept-android-licenses
```

Сервер amd64 после копирования бинарника на VPS:

```bash
chmod 755 /tmp/itom-linux-amd64 && sudo /tmp/itom-linux-amd64 install
```

Проверить подключение, загрузку, отдачу, одновременную передачу и страницы после отмены передачи. При сбое сохранить расширенные клиентские и серверные журналы. Исторические результаты FIELD45 относятся к предыдущим исходникам.
