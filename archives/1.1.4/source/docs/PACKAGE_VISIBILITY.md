# Полный каталог приложений и исключение Lint

В ITOM единственный экран выбора пакетов находится в «Правила → Приложения». Пользователь задаёт полный охват, исключения Direct или список приложений, включённых в VPN. Системные приложения доступны через отдельный переключатель; пакеты с общим UID выбираются вместе.

Каталог должен включать установленные пакеты текущего Android user/profile независимо от наличия launcher Activity. `<queries>` для MAIN/LAUNCHER ограничивает видимость компонентами и не обеспечивает этот контракт для приложений без значка запуска и произвольных shared-UID групп. Фиксированный список `<package>` также не подходит для заранее неизвестных установленных приложений.

Поэтому в main manifest намеренно сохранено `android.permission.QUERY_ALL_PACKAGES`. Это разрешение на видимость списка пакетов; оно не предоставляет доступ к данным других приложений или другим Android-профилям. Каталог используется локально; список пакетов не включается в диагностический экспорт. Фактическую маршрутизацию VpnService ещё предстоит подключить.

На **единственном элементе uses-permission** установлен `tools:ignore="QueryAllPackagesPermission"` с комментарием. Это точечное, осознанное исключение правила о необходимости широкого доступа. Оно не распространяется на application/manifest целиком. `abortOnError=true` сохранён, baseline и глобальные disable отсутствуют. Остальные ошибки Lint останавливают сборку.

`tools/check_sources.py` проверяет наличие ровно одного объявления, точный issue ID и область исключения. Offline-тесты воспроизводят отсутствие разрешения/исключения, дубликат и попытку расширить ignore на manifest/application.

Текущий source-комплект предназначен для ручной установки. Это решение не является заявлением об одобрении приложения магазином. При подготовке публикации необходимость широкого доступа оценивается отдельно по фактическому функционалу и требованиям выбранного канала распространения.
